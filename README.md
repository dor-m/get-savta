# Animated Scroll Website

This is a scroll-animated website using HTML5 Canvas and Video.

## How to use on GitHub Pages
1. Create a new repository on GitHub.
2. Upload `index.html` and `video.mp4` directly to the repository.
3. Go to the repository **Settings** -> **Pages**.
4. Under "Source", select the `main` branch and save.
5. In a few minutes, your site will be live!
